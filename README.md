A one-line fortune cookie for a crypto trader who has just been liquidated, written to /output/entry.txt by a tiny deterministic Python program. The cookie opens with the most familiar fortune trope of all — the lucky numbers — and the turn is that they are zeroes, because the wallet is empty, and the third "number" is the leverage he swore he would never use again.

## The line

> Your lucky numbers are 0, 0, and the leverage you swore you'd never use again.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
